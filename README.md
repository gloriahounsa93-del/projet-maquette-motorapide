# MotoRapide

**MotoRapide** est une maquette d'application mobile de réservation de taxi-moto réalisée uniquement en HTML. Ce projet présente l'identité visuelle ainsi que les quatre étapes clés du parcours utilisateur : la saisie du trajet, le choix du conducteur, le suivi de la course en temps réel et le paiement par Mobile Money ou en espèces suivi de l'évaluation du conducteur.
